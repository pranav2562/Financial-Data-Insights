# Business Segments Financial Performance
# Objective 
To know the performance of products at different countries and multiple segments
# Description 
To know about the products cost, profit and units sold over different countries & multiple segments.
# Tech Stack 
Cleaned and prepared data set using SQL from raw data set <br>
Combined different table using joins and validated them. <br>
Used Power BI to create interactive dashboard to express findings through visuals.
# Insights 

## Overview (page 1) <br>
### Overview of the dashboard. <br>
Added button filter to filter out years.<br>
Added the most country, most profitable segment, most profitable product by profit & most profitable product by units sold.<br>
Used donut chart to show the different countries and segments by units sold. <br>
Created a line chart to show the profits over the time frame.<br>
